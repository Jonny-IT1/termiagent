## 2. 🤖 Reddit (r/Python & r/LocalLLaMA) Post Template

**Title:** TermiAgent: An open-source CLI coding agent you can connect to ANY AI model (Ollama, Gemini, DeepSeek, Claude, OpenAI)

**Content:**
> Hi everyone! I wanted to share **TermiAgent**, a pure Python terminal AI agent that runs right in your console and works with local or cloud models.
>
> **Why I made it:**
> Existing terminal AI agents are often tied to specific proprietary endpoints. TermiAgent lets you switch models live mid-conversation (e.g. `/model ollama/qwen2.5-coder` or `/model gemini/gemini-2.0-flash`).
>
> **Quickstart:**
> ```bash
> pip install termiagent
> termiagent -m ollama/qwen2.5-coder
> ```
>
> **Features:**
> - File inspection & precise diff editing
> - Codebase grep/search
> - Terminal command execution
> - Modern Rich REPL with slash commands
> - Full MIT License (100% free open source)
>
> GitHub Repo: https://github.com/example/termiagent
